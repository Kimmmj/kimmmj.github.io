두 개의 UI 시스템이 제품 안에 공존했다

기술 전환기에 Mantine v6와 Bootstrap 기반 화면이 함께 운영되었습니다. 같은 역할의 컴포넌트가 다른 색상, 간격, radius를 사용하며 제품 일관성이 낮아졌습니다.

15핵심 컴포넌트

Mantine Props를 분석해 Figma Properties 구조로 옮겼습니다.

600+Variants

상태와 크기, 속성의 조합을 코드 구조에 맞게 정리했습니다.

구축 원칙

시각적 통일만 만드는 것이 아니라, 개발자가 실제 코드 속성과 연결해 사용할 수 있는 시스템을 만든다.

문서를 찾고 옮기는 시간을 줄였다

기존 핸드오프는 Figma Inspect 값을 코드로 옮기고, Props를 다시 맞추고, 결과를 검수하는 반복 작업이 필요했습니다.

  1. Props 기반 Properties 설계

    Mantine의 실제 속성을 Figma 컴포넌트 구조에 반영했습니다.

  2. Code Connect 연결

    디자인 컴포넌트를 Storybook과 코드 예제로 바로 연결했습니다.

  3. UX Writing 플러그인

    상황별 문구를 Figma 안에서 찾고 적용할 수 있게 해 불일치를 줄였습니다.

일관성과 속도를 함께 개선했다

반복 구현 시간은 15분에서 30초로 줄었고, 컬러 준수율은 55%에서 95%로 높아졌습니다.

시스템은 컴포넌트 수가 아니라 실제 제품에서 반복되는 의사결정 비용을 얼마나 줄였는지로 평가해야 한다는 기준을 얻었습니다.
